# 骨架、蒙皮与外观控制合同

仅当对象需要移动部位、姿态或可调外观时使用。静态模型不要为了满足模板创建无用骨架。角色需要骨架，并不自动需要正式动画片段。

## 先决定语义，再选实现

从用户描述提炼可独立控制的能力，而不是把每个形容词直接变成 shape key：

| 能力示例 | 通常考虑的实现 | 仍需确定/验证 |
| --- | --- | --- |
| 转身、扭头、抬手 | 根节点或关节旋转 | 局部轴向、范围、与父级组合 |
| 连续闭眼 | shape key、骨骼或其他可支持结构 | 半闭状态、闭合接触、目标引擎控制 |
| 肩膀下落、身体放松 | 骨骼姿态，必要时叠加形变 | 与抬手/坐姿的组合，避免双重变形 |
| 呼吸幅度 | 可调局部形变或骨骼参数 | 中间值和幅度；时间曲线由项目驱动 |

“困倦”可组合闭眼、肩膀下落和放松等基础通道；需要独立调节时不得只输出一个不可拆的 drowsy 形变。项目负责困倦状态、时间曲线、启动问好和点击看向等事件逻辑。小型预览驱动用于验证，不是正式动画交付。

选择依据是目标引擎可实现性、控制独立性、形体质量和复杂度。不能承诺任意 Blender driver/constraint 会被引擎继承；导出变形骨/形变目标，再在验证场景明确实现映射。

## 绑定原则

- 建立清楚的 root 与关节层级，区分编辑控制骨和实际变形骨；记录 rest pose、轴向、单位与局部/世界空间。
- 让头部、肩臂、躯干及腿等结构满足本角色用途，不强制某个通用人形骨架。角色坐姿和体操可作为变形测试，不自动制作正式动作序列。
- 检查蒙皮权重及有效影响数，避免未绑定顶点、意外跨部位牵拉和明显塌陷。目标上限来自 profile，不套用未确认数值。
- shape keys 保持需要的顶点对应关系，Basis/neutral 状态明确。每个要求的通道必须有实际非零效果；空命名占位不能算实现。
- 不把在 Blender 控制面板上“能调”当成引擎“能调”。导出前恢复约定中性状态；检查 morph 与 skinning 同时启用时仍有效。

## controls.yaml

按实际资产生成，不照抄示例数值。每个公开通道至少包括稳定 ID、中文含义、默认值/范围/单位、中性状态、Blender 绑定、目标绑定以及组合约束：

```yaml
schema_version: 1
asset_id: character-id
neutral_state: rest-pose
controls:
  - id: eye-close
    description: 眼睛闭合程度
    value: {default: 0.0, min: 0.0, max: 1.0, unit: normalized}
    source_bindings:
      - {object: Face, kind: shape-key, name: EyeClose}
    target_bindings: []
    combination_rules: []
    validation_cases: []
joint_controls: []
composite_examples: []
```

示例是格式，不是已实现的控制。关节项使用 kind: bone / node、真实骨名/节点路径、参考空间、旋转顺序或 quaternion 约定及有效范围；一个语义通道可以映射多个源部位。归一化 0–1 是可选接口约定，不对所有旋转或形变硬套同一单位。

target_bindings 在实际导入后填写 engine、对象/实体/节点路径、可寻址骨骼或形变名称、实际索引（如需要）、值映射及适配代码位置。不要假定源索引等于引擎索引；按名称解析并核验，缺失不能忽略。尚未验证则显式 unresolved，不能假写一个可用路径。

composite_examples 只说明基础通道如何组合及职责归属，不要求自动生成项目状态机。公开控制名称的变更会影响项目代码，返工时说明兼容性，不静默改名。

## 测试合同

为每个通道实际检查 neutral、代表性中间值和极值；非 0–1 范围按真实区间取值。返回 neutral 后不能残留漂移。测试至少覆盖影响当前用途的组合，而非指数级枚举：例如闭眼 + 抬头、放松 + 呼吸、抬手 + 肩膀下落。

检查是否连续、独立、无明显穿插/塌陷，以及骨骼姿态叠加形变是否发生双重变形。独立调节时，不应意外带动无关通道；有必要耦合则写入规则并让用户知道。

在 Blender 和最终目标引擎分别执行；保存控制值/骨骼姿态、截图或录屏、实际观察和失败原因。单个截图不能证明连续变化，至少检查多个值或实际播放范围。测试用姿态/曲线可留在独立 test collection/验证场景，不混入未经请求的正式动画集。
