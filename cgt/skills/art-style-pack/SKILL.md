# Art Style Pack

让非专业美术用户理解画风并保存可复用的 Style Pack。职责到风格档案交付为止；建立风格所需的校准图属于本 Skill，正式资产生产由独立流程完成。

## 路由与交付

- 分析、融合、校准或反馈：读 [analysis-and-calibration.md](references/analysis-and-calibration.md)。
- 确定路径、保存草稿、锁定版本或跨项目复用：读 [pack-storage.md](references/pack-storage.md)。
- 校准生图：读取环境内可用的 `imagegen` Skill，按其当前生图指引执行。其通用迭代与项目集成建议仅在本次请求范围内适用，不扩大样图预算或交付范围。无需加载正式生产 Skill。

读取与本次任务有关的项目说明和档案，继续已有进度。具体画风和图片保存到用户指定位置或按存储指引选择的项目目录，不写回 Skill 目录。

交付 Pack 时给出目录或 pack.yaml 路径、ID、精确版本、状态、规则及实际获批样图链接。另一会话或工具应能仅凭这些文件使用该 Pack，不要求保留当前对话。

## 工作流

1. 根据用户意图选择新建、修改、参考重建、原样复用或仅分析。需要保存时，沿用已有路径；缺省按存储指引在当前项目内选择不覆盖旧文件的新目录，说明过程文件和最终 Pack 的位置后继续。仅分析且未要求保存时在会话中交付。
2. 实际查看参考图。每张意向可选，缺省学习整体风格；有明确局部意向时只借鉴指定维度。缺图时说明，不编造分析。
3. 输出有视觉证据、通俗解释和必要术语的摘要，区分观察、推测和用户指定。摘要还包含系列范围、固定规则、允许变化项及拟定校准目标。
4. 用户请求建立并校准风格、直接试做样图，或已有明确制作授权时，展示摘要后继续校准；常规可逆细节作为假设记录。只有约定了摘要确认点，或关键风格冲突会显著改变结果时才等答复。制作授权不等于规则已批准；仅分析或保存规则时不额外生图。
5. 生成给定目标或本次范围内选定的同系列差异主体，辅助解释非专业反馈；清晰反馈直接采用，含糊解释先澄清。区分修改样图内容与修订整体风格。
6. 完成约定校准、保存与自检后，一并展示规则和样图供用户验收；同一次明确反馈可批准二者，无需重复走摘要确认。用户认可一张校准图及其规则即可锁定。模型自检不代替用户验收，额外迁移测试可选；规则变更创建新草稿，不覆写已锁定版本。

校准每次按用户请求的目标和数量执行。额外 A/B 样图先说明用途；没有相应授权时不增加生图数量，不自动无限重试。默认将后续生图所需的参考图、获批校准图、完整提示词、可见参数和批准依据实际复制进最终 Pack，按包内相对路径引用；原始绝对路径只作来源记录。外部引用只在用户明确选择时采用，按存储指引标注依赖。工具不暴露的模型身份或 seed 记录为未知，不承诺像素级复现。

## 两个 Skill 的交接

- 建立 Pack 不自动启动资产批量生产。用户同时要求建档和生产时，在规则与样图获批后继续使用 `art-asset-generation`，已有授权无需重新索取。
- 用户只要求按已有 Pack 生成时，交给生产流程，不重做风格访谈。
- 生产图可以作为修订证据；用户要求修改风格时，读取其图片、原始反馈及生成记录，在本 Skill 内创建新版本。
- 食物、油画收藏品都是系列示例，不是通用限制。每个 Pack 独立定义视觉规则 Style Spec 和主体范围 Series Scope。
- 仅生成栅格校准素材；SVG 化、裁剪、压缩及项目集成属于另行请求。
