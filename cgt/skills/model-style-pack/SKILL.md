# Model Style Pack

帮助非专业美术用户把模糊的 3D 风格意向变成可理解、可验证、可跨会话使用的风格包。第一版以 Codex 驱动 Blender 制作真实三维校准样例；截图不是模型，渲染图也不能替代可编辑的三维源文件。

## 按任务读取

- 分析参考、融合风格、解释反馈或选择校准样例：读 [analysis-and-calibration.md](references/analysis-and-calibration.md)。
- 确定位置、读取或保存 Pack、锁定版本和跨项目复用：读 [pack-contract.md](references/pack-contract.md)。
- 执行 Blender 制作、渲染或目标引擎校准：读 [blender-calibration.md](references/blender-calibration.md)。

全局 Skill 保存工作方法；项目风格、参考和模型保存到用户选定的项目或个人库，不写回 Skill 安装目录。无需先运行另一个 Skill 才能使用本 Skill。

## 工作流

1. 识别新建、修改、参考重建、原样复用或仅分析。读取已有约定，只问会改变结果的缺项。首次持久化或制作前确认过程文件与最终 Pack 的位置；已有明确路径沿用，用户授权自行安排时可直接安排。内置建议不是已获同意的路径。
2. 实际查看参考。作品名称可以是寻找参考的线索，不等于已经看过作品；只有名称时帮助定位代表性视觉材料并确认选择，不虚构细节。每张图的借鉴意向可选，未指定时分析整体风格。区分风格参考、角色身份、三视图和技术约束。
3. 给出有视觉证据的通俗摘要：固定规则、可变项、系列范围、造型/材质/渲染的分工，以及推测和冲突。**等待用户确认摘要再开始校准制作。** 已确认则续作，不重复访谈；用户明确改变本次确认流程时记录该指示。
4. 根据给定目标制作代表性 Blender 模型和可重开的校准场景，先看轮廓比例，再看材质光照。模型至少用能覆盖关键规则的多个视角呈现；一张图不能证明隐藏面的结构。校准目标属于该系列，附属道具不反客为主。
5. 让用户评价实际预览，辅助把“太硬”“不够像”等反馈转成少量具体修改。清楚的反馈直接执行；多种解释会显著改变结果时先问。每次修改记录保留项及作用范围，不把角色内容调整自动升级为全局风格变更。
6. 用户认可一个真实 3D 校准样例即可锁定视觉规则，不强制额外迁移样例。保存实际验证的视角、场景和范围，不能宣称所有主体或所有引擎均已验证。若本次还要求目标引擎校准，完成对应最小场景；引擎验证状态独立记录。
7. 按契约打包必要参考、获批样例、源文件和依赖，检查可移动性后交付精确版本。规则修改创建新草稿/版本；原样复用不重校准，不覆写已锁定内容。

## 范围与交接

- Style Pack 管视觉规则；项目技术配置管引擎、相机、着色系统及兼容约束；单个 Asset Brief 管角色身份、设计图、尺寸及控制需求。不要把某只北极熊的骨架或某项目的 RealityKit 配置写成所有 Pack 的强制规则。
- 已锁定 Pack 的正式单个或系列模型制作交给 `model-asset-generation`。用户同时要求建档和生产时，完成约定的确认即可继续，不重新索取同一授权。
- 只有分析/保存规则的请求可交付未校准草稿，不擅自制作模型。额外主体、成组对比或付费生成需属于已授权范围，不无限追加尝试。
- 2D 参考辅助图或纹理确有需要时才使用环境内的 `imagegen` Skill，先读其指引；它不能输出可绑定的三维网格。不要把栅格 Art Style Pack 静默当成已校准的 Model Style Pack。
- 无法完成指定引擎验证时，保留可用成果并说明缺少的环境或步骤；不得用 Blender 截图、导出成功或编译成功冒充运行时验收。
